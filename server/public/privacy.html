Hush 隐私政策

更新于 2026 年 10 月 31 日

Hush 是一个和 AI 一起学习的桌面应用。不登录也能完整使用，这时你的所有内容只存在你自己的电脑上。登录账号只是为了在你的几台设备之间同步。这份说明讲清楚：登录以后，我们的服务器上存了什么、存在哪里、谁能看到，以及怎么删除。

你和模型的对话不经过我们

你在 Hush 里提问时，请求由你的电脑直接发给你自己配置的模型服务商（例如 Anthropic、OpenAI、DeepSeek），用的是你自己的 API key。Hush 的服务器不转发、也看不到这些请求。服务商怎么处理你的数据，以它们各自的隐私政策为准。

登录后我们存了什么

  • 邮箱地址：用来登录和发送验证码。
  • 你同步的内容：project、会话和其中的消息（包括模型的回答）、追问、mark、note 及其历史版本、附件的原文件和从中提取的文字、服务商的名称和地址、模型的配置、全局提示词。
  • 登录凭证：只存它的哈希值，数据库泄露也不能用来登录。
  • 验证码发送记录（邮箱、IP 地址、时间）：用来防止有人滥发验证码，保留 2 天。
  • 服务器的访问日志：IP 地址、时间和请求的地址，不含你的内容，用于排查故障和防范攻击。

以下内容不会上传：模型服务商和联网搜索服务的 API key（每台设备各自填写）、窗口位置等只和这台设备有关的设置。

应用里没有广告、没有统计或追踪代码。我们不出售、不出租你的任何数据，也不用它来训练模型。

存在哪里，谁能看到

  • 数据库在美国的一台服务器上；附件存放在 Cloudflare R2；网站经 Cloudflare 代理；验证码邮件通过 Resend 发送（它只会拿到你的邮箱和验证码）。
  • 你的设备和服务器之间的传输全程加密（HTTPS）。
  • 服务器上的内容没有做端到端加密，所以运营者在技术上能够读取。我们不会主动查看，只有在你为排查问题提出请求、或法律要求时才会接触具体内容。如果你的内容非常敏感，可以选择不登录，只在本机使用。

保留多久，怎么删除

  • 你的数据会一直保留，直到你注销账号。退出登录不会删除云端数据。
  • 注销账号：在 Hush 的「设置 → 账号与同步」里点「注销账号」。云端的所有内容和附件会立即删除，不能恢复；你电脑上的内容不受影响。
  • 为了防止数据丢失，服务器每天备份一次。注销后，你的数据最长还会在备份里留 14 天，随备份轮换自动删除，期间不会被用于任何用途。
